# MobileShop
A full-featured e-commerce web application built with ASP.NET Core 10 MVC, ASP.NET Core Identity, Entity Framework Core, SQL Server, and Stripe Payment Gateway.

Features
User Registration & Login
ASP.NET Core Identity Authentication
Product Management
Category Management
Shopping Cart
Wishlist
Stripe Payment Integration
Order Management
Admin Dashboard
Responsive Design
Technologies Used
ASP.NET Core 10 MVC
Entity Framework Core 10
SQL Server
ASP.NET Core Identity
Stripe Payment Gateway
Bootstrap 5
