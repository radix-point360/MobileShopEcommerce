# MobileShop
A full-featured e-commerce web application built with ASP.NET Core 10 MVC, ASP.NET Core Identity, Entity Framework Core, SQL Server, and Stripe Payment Gateway.

# Features
1) User Registration & Login
2) ASP.NET Core Identity Authentication
3) Product Management
4) Category Management
5) Shopping Cart
6) Wishlist
7) Stripe Payment Integration
8) Order Management
9) Admin Dashboard
10) Responsive Design

# Technologies Used
1) ASP.NET Core 10 MVC
2) Entity Framework Core 10
3) SQL Server
4) ASP.NET Core Identity
5) Stripe Payment Gateway
6) Bootstrap 5
